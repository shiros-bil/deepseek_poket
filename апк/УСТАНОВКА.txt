DeepSeek Pocket 1.3.0

Установите DeepSeek-Pocket-1.3.0.apk поверх предыдущей версии.
Подпись прежняя, аккаунты, язык и тема сохраняются.

По умолчанию API без ключа. Старый автоматически созданный ключ снимается.
Свой ключ можно задать или удалить в настройках.
Base URL: http://127.0.0.1:9655/v1

Публичный адрес:
остановите API → Настройки → Публичный API → включите → сохраните → запустите API.
В Обзоре скопируйте HTTPS-адрес. В быстром режиме у клиента должно быть
stream: false: Cloudflare Quick Tunnel не поддерживает SSE.
Для постоянного адреса и SSE выберите постоянный туннель, укажите свой
Cloudflare Tunnel token и домен. В Cloudflare настройте маршрут на
http://127.0.0.1:9655. Публичный адрес без ключа доступен всем, кто его знает.

Настройки сервера доступны только после остановки API.
При выходе из настроек можно применить или отменить изменения.
Язык и тема применяются сразу.

История выключена: передаются новые сообщения и системный промпт.
Новый чат не получает скрытый контекст других разговоров.
Для продолжения переписки API-клиент должен присылать историю своего чата.
Счётчик сообщений хранит завершённые ответы всех сессий, включая регенерацию.

English и Dark — значения по умолчанию при новой установке.
Доступны V4.1 Flash и V4.1 Flash Thinking; поиск включён.
