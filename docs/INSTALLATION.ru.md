# Установка на Android

1. Скачайте `DeepSeek-Pocket-1.3.3.apk` из [последнего релиза](https://github.com/shiros-bil/deepsee_poket/releases/latest).
2. Откройте APK на телефоне и, если Android попросит, разрешите установку из выбранного источника.
3. Запустите DeepSeek Pocket, добавьте аккаунт DeepSeek и включите API в Обзоре.
4. Укажите в клиенте на телефоне `http://127.0.0.1:9655/v1`.

API-ключ по умолчанию не требуется. Перед включением доступа по Wi-Fi или публичного туннеля задайте ключ в Настройках. Для Cloudflare Quick Tunnel укажите `stream: false`. Для постоянного адреса и SSE выберите постоянный туннель.
