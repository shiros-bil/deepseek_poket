# DeepSeek Pocket

[English](README.md) · [Последний APK-релиз](https://github.com/shiros-bil/deepseek_poket/releases/latest)

DeepSeek Pocket превращает Android-телефон в небольшую API-точку, совместимую с OpenAI и работающую через веб-приложение DeepSeek. Это независимая экспериментальная адаптация и пример для тестирования AI-запросов через телефон. Это не официальный API или сервис DeepSeek. Поведение веб-клиента, доступность аккаунтов, лимиты и совместимость могут меняться.

## Возможности

- API-сервер работает на Android 8+ как фоновая служба.
- Доступны `deepseek-v4.1-flash` и `deepseek-v4.1-flash-thinking`, поиск включён.
- Совместимые форматы: OpenAI Chat Completions, OpenAI Responses и Anthropic Messages.
- Поддерживаются потоковые ответы, инструменты и изображения, если это позволяют веб-клиент и API-клиент.
- Запросы можно отправлять с этого телефона, из локальной сети или через дополнительный Cloudflare Tunnel.

## Скачать и установить на Android

Скачайте `DeepSeek-Pocket-1.3.3.apk` из [последнего релиза](https://github.com/shiros-bil/deepseek_poket/releases/latest), откройте APK на телефоне и разрешите установку из выбранного источника, если Android спросит. Запустите приложение, добавьте аккаунт DeepSeek и включите API-сервер.

Для приложения, запущенного на том же телефоне, используйте:

```text
http://127.0.0.1:9655/v1
```

Для клиента на ПК в той же Wi-Fi сети включите LAN-доступ в приложении и используйте локальный IP телефона, например `http://192.168.1.25:9655/v1`. Адрес зависит от вашей сети. Перед сетевым доступом задайте API-ключ в настройках. Cloudflare Tunnel позволяет подключаться по HTTPS из интернета.

## Проверка запросов

Список моделей:

```bash
curl http://127.0.0.1:9655/v1/models
```

Пример запроса к модели с телефона (при необходимости измените модель):

```bash
curl http://127.0.0.1:9655/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek-v4.1-flash","messages":[{"role":"user","content":"Привет"}],"stream":false}'
```

Если установлен API-ключ, добавьте `-H 'Authorization: Bearer ВАШ_API_КЛЮЧ'`. Для формата Anthropic используйте `POST /v1/messages`, для OpenAI Responses — `POST /v1/responses`. Другие маршруты: `GET /health`, `GET /readyz`, `GET /v1/model-capabilities` и `GET /v1/sessions`.

## Работа с проектом на ПК

Сам API-сервер работает на Android. Клонирование репозитория не запускает сервер DeepSeek на компьютере. ПК нужен, чтобы посмотреть или собрать Android-приложение, либо отправлять тестовые запросы на сервер, запущенный на телефоне.

1. Установите Git, JDK 17, Android Studio и Android SDK Platform 34 / Build Tools 34.0.0. Для сборки нативных компонентов нужен NDK r27c.
2. В PowerShell клонируйте проект вместе с подмодулем исходного API:

   ```powershell
   git clone --recurse-submodules https://github.com/shiros-bil/deepseek_poket.git
   cd deepseek_poket
   ```

3. Откройте папку в Android Studio и дождитесь Gradle Sync либо соберите приложение в PowerShell:

   ```powershell
   ./scripts/build.ps1
   python scripts/verify_apk.py
   ```

4. Установите собранный APK на подключённый Android-телефон или скачайте готовый APK из релиза. Сборка нативных библиотек, подпись APK и чистая установка описаны в [инструкции сборки](docs/BUILDING.md).
5. Чтобы отправлять запросы с ПК на телефон, подключите оба устройства к одной сети, включите LAN-доступ на телефоне и укажите клиенту `http://IP_ТЕЛЕФОНА:9655/v1`.

## Совместимость и ограничения API

Приложение адаптирует запросы для веб-клиента DeepSeek; это не официальный DeepSeek API. Модели, доступ аккаунта, ответы и ограничения задаёт сторонний веб-сервис. Параметры `temperature`, `max_tokens`, `max_completion_tokens` и `max_output_tokens` преобразуются в инструкции высокого приоритета. Это подсказки: веб-клиент не предоставляет управление температурой декодера и точное ограничение числа токенов.

Чтобы продолжать диалог, клиенту нужно отправлять актуальную историю переписки. По одиночному сообщению невозможно определить, к какому старому чату оно относится. Известная заглушка content filter может вызвать одну повторную попытку; восстановление ответа не гарантируется.

## Доступ по сети

Включите **Настройки → Публичный API**, чтобы запустить Cloudflare Tunnel.

- Быстрый туннель не требует аккаунта Cloudflare, но адрес меняется после перезапуска и SSE не поддерживается. Используйте `stream: false`.
- Постоянный туннель использует ваш Cloudflare token и домен, поддерживает постоянный адрес и SSE.
- Ограничьте browser origin при необходимости и установите API-ключ перед публикацией сервера. Любой, кто сможет подключиться к публичному адресу без ключа, сможет отправлять запросы через ваш аккаунт.

Подробнее: [ограничения Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).
