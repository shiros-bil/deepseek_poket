# DeepSeek Pocket

[English](README.md) · [Последний релиз](https://github.com/shiros-bil/deepsee_poket/releases/latest)

DeepSeek Pocket запускает API-сервер в формате OpenAI на Android-телефоне. Требуется Android 8 или новее. APK содержит версии для ARM64, ARMv7 и x86_64.

## Скачать

Установите APK из [последнего релиза GitHub](https://github.com/shiros-bil/deepsee_poket/releases/latest). Обновление сохраняет добавленные аккаунты и настройки.

## Быстрый запуск

1. Установите APK и добавьте аккаунт DeepSeek во вкладке **Аккаунты**.
2. Запустите сервер во вкладке **Обзор**.
3. На телефоне используйте Base URL `http://127.0.0.1:9655/v1`.
4. API-ключ по умолчанию не требуется. Задайте его в **Настройках**, если открываете доступ по сети.

Доступны модели `deepseek-v4.1-flash` и `deepseek-v4.1-flash-thinking`. Поиск включён у обеих. Поддерживаются OpenAI Chat Completions, Anthropic Messages и Responses, а также инструменты, изображения и потоковые ответы.

## Публичный доступ

Включите **Настройки → Публичный API**, чтобы вместе с сервером запускался Cloudflare Tunnel. HTTPS-адрес появится в Обзоре.

- **Быстрый туннель** не требует аккаунта Cloudflare, но его адрес меняется при перезапуске. SSE не поддерживается — укажите `stream: false` в клиенте.
- **Постоянный туннель** использует ваш токен Cloudflare и домен. Он поддерживает постоянный адрес и SSE.
- Доступ сайтов можно разрешить всем или ограничить списком origin. Для публичного адреса рекомендуется задать API-ключ.

Подробнее: [ограничения Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).

## Настройки чата

Настройки сервера сохраняются при остановленном API. Если уйти из настроек с несохранёнными изменениями, приложение предложит применить или отменить их.

Настройки истории повторно передают историю, которую прислал API-клиент. Чтобы сохранить контекст, клиент должен отправлять сообщения текущего диалога. Если пришло только одно сообщение, сервер не может понять, продолжает ли оно старый чат, поэтому использует отдельный контекст.

API принимает `temperature`, `max_tokens`, `max_completion_tokens` и `max_output_tokens` и добавляет их в отдельный блок инструкций высокого приоритета. Это подсказки для модели: DeepSeek Web не предоставляет управление температурой декодера, а точный лимит токенов гарантировать нельзя.

Если DeepSeek заменил ответ известной заглушкой content filter, API может один раз повторить запрос в новом чате с переданной клиентом историей и перехваченным частичным ответом. Потоковый текст проверяется до отправки клиенту. Восстановление не гарантируется.

## Сборка

Требуются Java 17, Android SDK Platform 34, Android Build Tools 34.0.0, Gradle 8.7 и Android NDK r27c. Нативные библиотеки Node.js Mobile и cloudflared не входят в Git. Инструкции: [`docs/BUILDING.md`](docs/BUILDING.md).

```powershell
./scripts/build.ps1
python scripts/verify_apk.py
```

Исходный API включён как Git-подмодуль `upstream`. Лицензии и уведомления компонентов перечислены в [`THIRD-PARTY.md`](THIRD-PARTY.md) и ресурсах приложения.
